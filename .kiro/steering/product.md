# Product: Cursed Code Review

A code review you can see. Bugs become monsters on the exact lines where they hide; applying the fix banishes the monster and the "room light" rises.

- Category: Kiroween 2026 · Costume Contest (haunting, polished UI that serves the app's function).
- Audience: developers and hackathon judges. Judges must reach monsters in one click (cursed samples).
- Three entry doors: cursed sample, pasted code, GitHub pull request (changed lines only).
- Tone: spooky but clear. Every explanation has a plain version ("What is wrong") and an "Explain it simply" version.
- Never hide information behind theme: severity, line and fix are always readable; the theme decorates, it does not obscure.
